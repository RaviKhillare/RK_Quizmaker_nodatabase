Google Sheet Exam Master Format

Universal 8-column layout supporting all 6 educational question types

How to structure your Google Sheet:

Row 1 must contain column headers. Enter questions starting from Row 2 matching the structure below.

Type Question / Prompt Option A / Left / Front Option B / Right / Back Option C Option D Correct Answer Explanation / Hint
mcq What is the brain of the computer? CPU RAM Hard Disk Motherboard 1 (or CPU) Central Processing Unit manages execution.
fill_blank The shortcut key to copy text is Ctrl + ___. — — — — C Ctrl+C copies selected items.
true_false Python is a compiled-only programming language. True False — — 2 (or False) Python is an interpreted language.
flashcard Cache Memory Extremely high-speed buffer between CPU and RAM. — — — — Flip to see concept definition.
match Match network protocols to default ports: HTTP:80 HTTPS:443 DNS:53 SSH:22 ALL Key-value pairs separated by colons.
reorder Arrange the IPO cycle steps in order: Input Process Output Storage 1,2,3,4 Standard computer execution pipeline.
Multiple Choice (mcq)

Put options in cols C-F. Answer can be 1, 2, 3, 4 or A, B, C, D.

Fill Blank (fill_blank)

Put target word in Answer col. Comma-separate synonyms (e.g. DHCP, Dynamic Host).

True / False (true_false)

Col C is True, Col D is False. Answer can be 1 (True), 2 (False), or True/False.

Flashcard (flashcard)

Question col = Card Term/Front. Col C = Detailed Definition / Back.

Match Pair (match)

Write each matching item as Left:Right (e.g. HTTP:80) across columns C to F.

Reorder (reorder)

Place steps in correct chronological order across Cols C to F. The player auto-shuffles them.
