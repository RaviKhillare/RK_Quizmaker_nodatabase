3‑Step: Deploy Google Apps Script Web App (Quick)

  1. Open Google Sheets → Extensions → Apps Script. Replace Code.gs with the provided Code.gs and Save.
  2. Deploy → New deployment → Select "Web app", enter description, set "Who has access" to "Anyone", and click Deploy. Copy the "Web app" URL (ends with /exec).
  3. Paste the Web App URL into the input above, click Save, then Test Connection.
